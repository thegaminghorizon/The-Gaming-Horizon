## ✦ Copyright Review Matrix

| **Compatibility** | Can it legally be included here? |
| **Attribution** | Is attribution required? |
| **Modification** | Must modifications be identified? |
| **Branding** | Does use imply false official status? |
| **Third-Party IP** | Does it contain external protected material? |
| **Privacy** | Does it expose personal information? |
| **Security** | Does it expose confidential information? |
| **Distribution** | Can it legally be redistributed? |
| **Documentation** | Are required notices recorded? |

<a id="copyright-quality-gate"></a>

## ✦ Copyright Quality Gate

Before adding significant external or creative material:

- [ ] Creator or source is known
- [ ] Reuse rights are understood
- [ ] Applicable license is compatible
- [ ] Attribution requirements are satisfied
- [ ] Required notices are preserved
- [ ] Third-party IP was reviewed
- [ ] Brand representation is truthful
- [ ] No private information is exposed
- [ ] No confidential information is exposed
- [ ] Distribution rights are sufficient
- [ ] `THIRD-PARTY-NOTICES.md` was updated if necessary
- [ ] `BRAND.md` was considered for brand assets

<a id="copyright-golden-rules"></a>

## ✦ Copyright Golden Rules

### `01`

**The root `LICENSE` contains the authoritative Apache 2.0 license terms.**

### `02`

**Do not modify the Apache 2.0 legal text for visual presentation.**

### `03`

**Never assume that software licensing and branding permission are identical.**

### `04`

**Only contribute material you have the right to contribute.**

### `05`

**Respect third-party licenses, attribution, and notices.**

### `06`

**Do not remove required copyright or license notices.**

### `07`

**Screenshots may contain multiple layers of copyright and privacy interests.**

### `08`

**Showcase artwork is conceptual material, not automatic product evidence.**

### `09`

**AI-assisted material still requires copyright and licensing review.**

### `10`

**Do not claim trademark registrations, partnerships, or ownership that has not been established.**

### `11`

**Forks and derivatives should not misrepresent themselves as the official Gaming Horizon project.**

### `12`

**When rights are unclear, verify before distributing.**
