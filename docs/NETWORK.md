<a id="network-principles"></a>

## ✦ Network Principles

### `01` — One Identity

Every official destination should clearly belong to the same Gaming Horizon
project.

---

### `02` — Different Platforms, Different Responsibilities

The website, Discord, GitHub, X, and Instagram should not all attempt to serve
the exact same function.

---

### `03` — Official Before Convenient

Important project communication should point toward known official
destinations.

---

### `04` — Consistency Before Volume

A smaller number of maintained channels is better than many abandoned
accounts.

---

### `05` — Truth Before Promotion

Network communication should not exaggerate project state.

---

### `06` — Security Before Reach

Expanding onto another platform is not valuable if the project cannot maintain
it securely.

---

### `07` — Accessibility Across Destinations

Public information should remain understandable wherever practical.

---

### `08` — The Website Remains the Platform Gateway

Social channels should complement rather than replace the browser-first
Gaming Horizon experience.

---

### `09` — GitHub Remains the Development Gateway

Repository and development information should be anchored to the official
GitHub organization and repository.

---

### `10` — Discord Remains the Community Gateway

Community participation should have a clear official destination.

---

### `11` — Social Networks Amplify, They Do Not Define

Gaming Horizon should not depend on one social platform for its identity.

---

### `12` — Expand Deliberately

A new network destination should exist only when it has a meaningful role.

---
