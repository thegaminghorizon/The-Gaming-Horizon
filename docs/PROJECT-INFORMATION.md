## ✦ State Hierarchy

```text
CONCEPT
   │
   ▼
PROTOTYPE
   │
   ▼
EXPERIMENTAL
   │
   ▼
IN DEVELOPMENT
   │
   ▼

   │
   ▼
```

```text
PAUSE

RETURN TO RESEARCH

```

## ✦ Product-State Integrity

Avoid:

```text
PAGE A:
COMING SOON


PAGE B:
AVAILABLE


PAGE C:
CONCEPT
```

for the same system without a valid explanation.

Project state should remain synchronized across relevant surfaces.
